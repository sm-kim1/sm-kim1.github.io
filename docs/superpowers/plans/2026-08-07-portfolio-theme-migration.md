# online-cv 테마 이전 계획 — 종료 기록

2026-09-09 정리. 완료되었거나 후속 설계로 대체된 실행 단계와 체크박스를 제거했다. 이 문서는 현재 작업 목록이 아니다.

당시 계획은 기존 정적 포트폴리오를 online-cv 기반 Jekyll 사이트로 옮기고, 한·영 데이터와 프로젝트·기술 스택 렌더링을 구성하는 것이었다. 이후 자체 테마와 한국어 단일 사이트로 전환해 online-cv, 영어판, Docker 기반의 당시 실행 절차는 현재 구조에 적용하지 않는다.

기술 스택을 항목 목록으로 표시하고 프로젝트에 기간·역할·설명·선택 이미지를 두는 데이터 구조는 현재 사이트에 이어진다. 현재 실행 방법과 소스 구조는 [README](../../../README.md)와 [AGENTS.md](../../../AGENTS.md)를 따른다.

당시 설계 배경은 [설계 문서](../specs/2026-08-07-portfolio-theme-migration-design.md)에 보관한다. 현재 구현을 과거 계획에 맞춰 되돌리지 않는다.
