# 자체 테마 재디자인 계획 — 종료 기록

2026-09-09 정리. 완료되었거나 후속 설계로 대체된 실행 단계와 체크박스를 제거했다. 이 문서는 현재 작업 목록이 아니다.

당시 계획은 online-cv와 부속 플러그인·영어판을 제거하고, 경력 데이터를 회사 아래 역할별로 통합하며, 자체 레이아웃과 SVG 다이어그램을 만드는 것이었다. 해당 데이터 구조와 SVG 형식은 현재 사이트에서 사용한다.

당시 IBM Plex·청록/테라코타 웹 테마와 섹션 include 구성은 이후 Pretendard 기반 디자인으로 대체됐다. 인쇄 페이지 삭제 계획도 후속 A4 4페이지 구성으로 대체되어 현재 `/print/`를 유지한다. SVG 내부 팔레트는 웹 테마와 별도로 유지한다.

당시 설계 배경은 [설계 문서](../specs/2026-08-10-site-redesign-design.md)에 보관한다. 현재 실행 방법과 소스 구조는 [README](../../../README.md)와 [AGENTS.md](../../../AGENTS.md)를 따른다.
