# Pretendard 미니멀 리디자인 계획 — 종료 기록

2026-09-09 정리. 구현과 검증을 마친 실행 단계·체크박스를 제거했다. 이 문서는 현재 작업 목록이 아니다.

현재 사이트는 Pretendard와 라이트·다크 색상 토큰, 공용 네비게이션·푸터·이미지 확대, 대표 작업 3건, 케이스 페이지 3개, 웹 이력서와 A4 4페이지 인쇄 구성을 사용한다. 스타일은 `_sass/portfolio.scss`, 공용 문서는 `_layouts/default.html`에 있다.

최종 구현에서 `/print/`도 공용 레이아웃을 사용한다. 홈 카드는 별도 링크와 이미지 확대 버튼을 가진 `article`이며, 확대는 키보드로 조작하는 native dialog다. 따라서 당시 독립 print 문서와 카드 전체 `a` 요소를 전제로 한 절차는 현재 구현에 적용하지 않는다.

빌드, 주요 페이지·내부 참조, 모바일/데스크톱, 라이트/다크, 키보드 확대, 동작·투명도 감소, SVG 5개와 A4 4페이지 출력을 확인했다. 웹 테마와 별도로 유지하는 SVG의 기존 팔레트는 제거 대상이 아니다.

당시 설계 배경은 [설계 문서](../specs/2026-09-03-apple-minimal-redesign-design.md)에 보관한다. 현재 실행 방법과 소스 구조는 [README](../../../README.md)와 [AGENTS.md](../../../AGENTS.md)를 따른다.
